## 🛠️ About the Project
This project is built using a Node.js backend setup to handle core server-side logic and endpoints.

* **`server.js`**: The main entry point for the Node.js server.
* **`package.json`**: Manages the project dependencies and scripts.
* **`.gitignore`**: Specifies untracked files that git should ignore (like `node_modules`).
